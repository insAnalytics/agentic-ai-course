<Subsection title="Closing synthesis — predict, then check" variant="a">

This isn't graded — it's a chance to build real intuition for what
drives token count before the rest of this module starts relying on
that intuition being there.

Before checking, predict which of these four inputs will tokenize into
the *most* tokens per character, and which into the *fewest*:

1. `"The cat sat on the mat."` — plain, common English words
2. `"The agentic AI framework uses Pydantic for validation."` — the
   same rough length, but denser with technical jargon
3. The same sentence as (1), translated into a language you speak or
   are curious about — type it into the third row below
4. `"xqzflorp wibbleton"` — invented, nonsense words that share no real
   pieces with anything in the vocabulary

Then use [the interactive tokenizer](/01-llm-foundations/01-tokenization/02-subword-tokenization-bpe/#what-this-actually-looks-like-on-real-words)
below — the same tool from the previous concepts, pre-filled with all
four — to check:

*Reasoning to check your prediction against:* (1) should tokenize
efficiently — short, common words merge into single tokens easily. (2)
should cost noticeably more than its word count suggests, since
`"agentic"` and `"Pydantic"` split into pieces the way [the earlier tokens-in-practice example showed](/01-llm-foundations/01-tokenization/03-tokens-in-practice-and-cost/#the-same-sentence-tokenized-differently-depending-on-what-it-contains).
(3) will very likely cost more tokens than (1) for the same meaning,
for exactly the reason covered in that same concept — unless you
picked a language the tokenizer already represents efficiently, which
is itself worth noticing. (4) is the most revealing case: nonsense
words have no learned merges to fall back on at all, so they should
tokenize into unusually small, choppy pieces — direct, hands-on
confirmation that [BPE's fallback to smaller pieces](/01-llm-foundations/01-tokenization/02-subword-tokenization-bpe/#the-fix-pieces-small-enough-that-nothing-is-ever-truly-unknown)
is a real, observable behavior, not just a claim in the reading.
