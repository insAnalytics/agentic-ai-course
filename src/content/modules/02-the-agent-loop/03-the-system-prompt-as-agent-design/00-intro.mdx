<WhyItMatters>
  The system prompt is the single highest-leverage piece of an agent's
  design — get it vague, and every downstream lesson in this module
  (control flow, planning, reflection) inherits that ambiguity as
  unpredictable behavior. Everything in this lesson is really
  [Lesson 2's prompting technique](/02-the-agent-loop/02-prompting-fundamentals/00-intro/),
  applied deliberately to the one piece of prompt text that shapes an
  agent's behavior across its entire run, not just one response.
</WhyItMatters>
