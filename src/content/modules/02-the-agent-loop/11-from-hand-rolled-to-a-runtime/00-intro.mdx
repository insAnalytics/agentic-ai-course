<WhyItMatters>
  This lesson — and this module — closes with the same honest register it
  opened with in [Lesson 1](/02-the-agent-loop/01-agents-workflows-and-the-loop/00-intro/):
  a framework isn't magic, and it isn't strictly better than hand-rolled
  code either. It's the exact same loop, dispatch, state, and guards this
  module built concept by concept, now packaged for reuse at the cost of
  direct visibility. Having built every one of those pieces yourself is
  what makes that trade a real decision, not a leap of faith.
</WhyItMatters>
