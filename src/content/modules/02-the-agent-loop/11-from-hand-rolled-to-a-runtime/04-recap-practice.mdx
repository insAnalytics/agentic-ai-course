[Lesson 9's reflection](/02-the-agent-loop/09-reflection-and-self-critique/00-intro/)
— every mechanism a real framework like LangChain packages was built
here first, by hand, understood at the level of every line. That's the
actual point of this module: not that hand-rolling is always the right
choice, but that choosing a framework afterward is a genuine, informed
decision — never a black box accepted on faith.
