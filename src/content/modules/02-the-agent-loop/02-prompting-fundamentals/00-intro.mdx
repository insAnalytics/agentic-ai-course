<WhyItMatters>
  Every technique in this lesson is the deferred payoff of something
  Module 1 explained but didn't teach you to actually *use* — in-context
  learning, message structure, chain-of-thought's underlying mechanism.
  More directly: the system prompt, tool descriptions, and every
  instruction an agent runs on for the rest of this module are themselves
  prompts — write them vaguely, and the agent's *behavior*, not just its
  writing style, becomes unpredictable in exactly the ways
  [Lesson 1](/02-the-agent-loop/01-agents-workflows-and-the-loop/03-the-honest-case-for-not-using-an-agent/)
  warned about.
</WhyItMatters>
