<WhyItMatters>
  Everything this module has built so far ends when the session does. A user
  who explained their preferences last week has to explain them again, and a
  conclusion the agent worked hard for is gone. The tempting fix, starting
  each session with the last one's transcript, brings back every problem from
  [Lessons 1–5](/04-context-and-memory/01-the-context-budget/00-intro/) at a
  larger scale, along with facts that have since gone stale.

  Long-term memory is the alternative: a small, selected, per-user record of
  what lasts. This lesson lays out its architecture. The next three build it,
  decide what goes into it, and keep it from rotting.
</WhyItMatters>
