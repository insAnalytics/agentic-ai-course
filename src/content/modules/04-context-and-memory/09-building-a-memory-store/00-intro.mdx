<WhyItMatters>
  [Lesson 8](/04-context-and-memory/08-long-term-memory/00-intro/) drew the
  architecture: storage, retrieval and injection, over three kinds of memory.
  This lesson builds it. Two things decide whether that build is safe and
  affordable. The first is scoping: one user's memories must never reach
  another user's session, however the model is steered. The second is
  placement: memory arrives in every session, so where it goes in each request
  decides how much every session costs.
</WhyItMatters>
