A "tool" in an agent system is nothing more than a plain function with a
name, some arguments, and a return value. Here's the smallest possible one:

<LiveDemo client:load code={`def calculator(expression: str) -> str:
    return str(eval(expression))

print(calculator("2 + 2"))`} />
