<WhyItMatters>
  Every lesson after this one reads runs: to find out how the agent fails,
  to grade it, to check the graders, and to compare one version of the agent
  with another. A run that wasn't recorded can't be evaluated, and a run
  recorded as a flat list of events can't answer the questions that matter:
  which step led to which, what failed first, what the model saw when it
  went wrong. This lesson builds the recording the rest of the module
  depends on, in the format the industry's tools share, and the replay that
  lets real runs be rerun in the browser.
</WhyItMatters>
