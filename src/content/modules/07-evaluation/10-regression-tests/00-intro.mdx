<WhyItMatters>
  Everything around an agent keeps moving: prompts get edited, models get
  re-served, checks get fixed. Only a rerun shows what each change did.
  Here, an FP8 server passed unnoticed by the config hash and unharmed; a
  two-line prompt edit fixed one failure and left another; and a fix to
  Module 6's layers improved two layers while shipping two bugs in a
  third, caught by exactly the run this lesson builds.
</WhyItMatters>
