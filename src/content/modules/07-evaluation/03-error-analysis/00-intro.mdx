<WhyItMatters>
  Graders, suites and monitors all rest on knowing what actually goes wrong,
  and that only comes from reading runs. The lessons after this one build
  tests and graders for the failures found here: a written-in-advance list
  would have missed two of them, and a code check written before the runs
  existed got eight of fifty traces wrong. This lesson is where the module
  stops guessing and starts measuring what this agent really does.
</WhyItMatters>
