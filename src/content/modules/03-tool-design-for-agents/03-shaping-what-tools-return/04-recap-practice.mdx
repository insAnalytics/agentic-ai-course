  correctAnswer={{
    code: `import json

def search_agents_by_model(model: str, registry: dict, offset: int = 0, limit: int = 2) -> str:
    matches = [name for name, info in registry.items() if info["model"] == model]

    if not matches:
        existing_models = sorted({info["model"] for info in registry.values()})
        return (
            f"Error: no agents use model '{model}'. "
            f"Models in use: {', '.join(existing_models)}."
        )

    total = len(matches)
    page = matches[offset:offset + limit]
    next_offset = offset + limit if offset + limit < total else None

    return json.dumps({"model": model, "agents": page, "total": total, "next_offset": next_offset})`,
    explanation:
      "Each part of the lesson shows up here. The page is capped by limit (the cost of oversized results). total and next_offset tell the model how much exists and how to get more, so partial data is never mistaken for the whole (truncation and pagination). The result is parseable JSON with labeled fields, including a next_offset the model can pass straight back into its next call (structured results). The error names the failed search and shows what would work. sorted(...) just makes the error's order stable, since sets have no guaranteed order.",
