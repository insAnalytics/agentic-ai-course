<WhyItMatters>
  The web is where most of what an agent needs to know actually lives:
  anything newer than the model's training, and anything it was never
  trained on. Search and fetch are how agents reach it, and they're among
  the most common tools there are, both hand-built and offered by model
  providers directly.

  They're also the first tools in this course whose results were written
  by strangers. Every earlier tool returned text you controlled. A fetched
  page contains whatever its author put there, including text written to
  steer an AI that reads it, and that text arrives in the model's context
  with everything else. This lesson builds web tools that are cheap,
  useful and honest about what they return, and ends on the point the next
  lesson, on the tool threat model, takes further: content from outside is
  input to be read, never instructions to be followed.
</WhyItMatters>
