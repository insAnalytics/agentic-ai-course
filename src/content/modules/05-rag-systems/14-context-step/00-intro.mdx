<WhyItMatters>
  Module 4 built an agent that manages its own context, and everywhere it
  chose something by relevance, it matched words. This lesson kept every one
  of those places and changed how they judge relevance, measuring each change
  on labelled tasks. Some improvements needed more than a swap: fusion is only
  as good as its rankings, a threshold can find candidates but not verdicts,
  and a better relevance term needed new weights. Then retrieval itself joined
  the agent, as a tool whose results the context step manages like any other.
</WhyItMatters>
