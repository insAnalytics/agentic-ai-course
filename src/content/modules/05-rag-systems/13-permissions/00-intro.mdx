<WhyItMatters>
  A retrieval system hands the model whatever its index contains. Unfiltered,
  this module's pipeline put restricted documents in front of an all-staff
  reader for 20 of 57 questions, and a single planted wiki edit ranked first
  for the rate-limit question and passed every citation check. Neither problem
  can be fixed by instructing the model. Both are fixed in code and process:
  what each reader's search can see, and who can put text into the index.
</WhyItMatters>
