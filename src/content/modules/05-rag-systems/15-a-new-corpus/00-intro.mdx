<WhyItMatters>
  Fourteen lessons each improved one part of retrieval, measured on its own.
  An agent builder facing a new corpus needs the other view: which parts to
  build first, which to add only when a measurement asks for them, and
  whether the whole system does what its parts promised. This lesson runs
  the finished pipeline end to end, lays out what each stage bought, checks
  the result on questions none of the choices were made on, and turns the
  module into a plan.
</WhyItMatters>
